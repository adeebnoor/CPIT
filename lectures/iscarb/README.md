# iSCARB nine-chapter learning path

The release publishes Chapters 10–17 and 20 with nine after-class assignments.
Each self-contained lecture separates a 16–19-unit classroom route, required source review, and the optional iSCARB toolkit. The source ledger indexes all 579 supplied slides. The original source packs are downloadable for full layout and vector diagrams.

The supplied syllabus lists eleven course learning outcomes. Each chapter has five local objectives mapped to relevant syllabus outcomes. Code Coverage is practised in the coverage step of every Python build in Assignments 3–9: the harness measures line and branch coverage of the student’s code by the student’s own tests (gate outcomes for the Chapter 12 fault tree), and the student changes one input, reruns and names the branch still untested (course outcome 11).

A1/A2 draft identities and scoring remain unchanged. A3–A9 reuse the verified commit/reveal workflow with separate chapter identities, five criteria, four scoring levels, fictional transfer cases and AI disclosure. No student work is transmitted by these pages.

The explicit catalog in curriculum/publication.json governs staging and checks exact lecture bytes, embedded images, assignment identities, reveal separation and local links. Automatic generation remains disabled. The user authorized the nine-chapter scope on 2026-09-20.
