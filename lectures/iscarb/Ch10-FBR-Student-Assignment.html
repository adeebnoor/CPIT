2 · PART A · 15 MINUTES

Assessed scenario · AI-containing system

A fictional university uses a generative-AI operations assistant during course registration. It recommends CONTINUE, FAILOVER or HOLD. Two application servers are redundant, but both call the same model, prompt template and retrieval service. A quiet-period server failover test passed; no peak-load test covers AI outage, contradictory recommendations or a wrong recommendation. Operators can ignore the assistant, but the current procedure does not require an independent check before acting. Decide whether the assistant may control the action, remain advisory-only, or be disabled for the peak window.

Teaching simulation. Produce a decision record using the stated facts. Do not invent test results or certify a real service. Mark missing evidence as unmeasured and specify how you would obtain it.

Keep the complete written response to about 180–260 focused words; use compact tables or notation. Include the source application and transfer answer in that budget. No external experiment is required. State facts, assumptions and proposed evidence separately. Quote or cite the assigned source precisely; explain its role. Report actual study time at the end.
