Assignments and assessment

Assignment 1 retains 4 points; Assignments 2–9 retain 5 points. All current rubrics use four performance levels (1, 0.75, 0.5, 0 per criterion). Source application and transfer reasoning are included within these totals. These task points are not course-grade percentages.

The core workflow remains stable while the artifact progresses: measure, trace, test, recover, compare, specify a contract, reason about remote failure, and integrate across owners. Each assessed case is fictional; any additional evidence must be marked proposed or unknown.

NCAAA, Jaheziah and iSCARB

Knowledge, skills and accountable judgment are made visible through objectives, practice and artifacts. The course files do not establish a current approved national item-weight or departmental mapping. Accordingly, this release does not claim accreditation, official test equivalence or guaranteed national-test readiness.

The full iSCARB toolkit preserves the six engineering capabilities, Decision Card, AI verification gate and practice explanations. These remain tools to support learning rather than a second set of chapter content to race through.

Light first load; complete sources on demand

The lecture shell, shared runtime and active figure load for teaching. Original PDFs, PowerPoints, full source text and image galleries load when opened. No source topic is removed merely to reduce the initial download.

Every chapter has 20 main slides, exactly five local objectives, three active stations and the canonical 20-rule map. Existing assignment raw points and commit/reveal logic are unchanged. The original source is authoritative for historical wording, diagrams and mathematical layout; authored qualifications are labelled.
