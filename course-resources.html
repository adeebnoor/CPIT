Assignments and assessment

Assignment 1 remains 4 points; Assignments 2–9 remain 5 points. All nine current assignments are AI-only engineering cases and use the same visible quarter-point rubric levels (1, 0.75, 0.5, 0).

Each task assesses an AI-containing system using the chapter mechanism: reliability, safety, security, resilience, reuse, component contracts, distributed effects or systems-of-systems governance. Blackboard is the official submission and grade record; students upload one machine-readable JSON file.
