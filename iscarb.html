Notes

Assessment

How a chapter is assessed

Class is twenty slides and one shared case. The assignment uses a different case. State the fit, the bound, the act and the evidence. Commit before the stress test, then justify any refit. Export and submit on Blackboard.

Practice

An assistant that questions you

It reads the approved lecture and presses a vague claim. It does not write the assignment. AI is a transfer/practice layer inside the chapters. The assessed assignment stays the chapter task, not a separate AI-only outcome. Part A, the stress test and the submission stay on this site.

Read https://adeebnoor.github.io/CPIT/ai/iscarb-coach.md and https://adeebnoor.github.io/CPIT/ai/ch13.md, then coach me on Chapter 13.

Change the chapter number. Declare any AI use. Do not share your name or student ID. If a link will not open, download the file and attach it.
