Chapter 10 · After class

Apply what you learned.

Use dependability principles to advise on a fictional campus registration service. Make your first decision, then respond to new evidence.

30–40 minutes4 pointsDue date: LMS

What you will do

  1. Try an ungraded warm-up with a hidden explanation.
  2. Write FIT → BOUND → ACT + EVIDENCE for a new scenario.
  3. Commit Part A, read the new information, then justify RETAIN, REVISE or REPLACE.
  4. Review your work, declare AI use, export as PDF and submit through the LMS.

The lecture is open for reference. This assignment assesses your own reasoning. The rubric is visible before you begin; automated checks only check completeness.

Start or resume

Use the same Student ID and browser each time. Your ID and answers are saved on this device, not sent to an instructor by this page.

Enter your own ID exactly as you will use it for submission. This is a local draft label, not a university sign-in.

What happens when I commit Part A?

It freezes your first response before the new evidence appears. Review it before confirming. You can continue editing Part B and export a draft backup. This sequence supports honest reflection; it is not a secure examination system.

Can I recover work from the previous edition?

Open with the same Student ID and browser. If a previous-edition draft exists, you can download it. The revised assignment has a separate draft so the two scenarios cannot be mixed.
