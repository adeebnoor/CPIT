    ONE OFFICIAL WORKFLOW

    Website → JSON → Blackboard → rubric grading

    1. Solve on this site. The page checks completeness and preserves Part A before STRESS is revealed.
    2. Read the worked example and rubric before answering. Every current assignment is AI-only.
    3. Download one Blackboard JSON. PDF and .md are optional personal copies.
    4. Upload the JSON to Blackboard. Blackboard is the official identity, timestamp, receipt and grade record.
    5. Batch grading. Submitted JSON files are validated and scored against the published rubric; uncertain, contradictory or low-confidence cases are sent to instructor review.
